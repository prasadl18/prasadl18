### 🧠 About Me  

I’m **Prasad Limbekar**, a passionate **Full Stack Developer** with a deep interest in building efficient, scalable, and visually appealing web applications. I believe that great software is not just about code — it’s about solving real problems, enhancing user experience, and crafting digital products that make a difference. My work reflects my commitment to writing clean, maintainable, and high-performing code while continuously improving my technical and creative skills.  

I specialize in the **MERN stack (MongoDB, Express.js, React, and Node.js)** and enjoy working on both the frontend and backend to bring complete ideas to life. On the **frontend**, I focus on creating responsive and modern interfaces using **React, Tailwind CSS, HTML5, CSS3, and JavaScript**, ensuring that every design element contributes to usability and performance. On the **backend**, I work with **Node.js and Express.js**, developing secure RESTful APIs and integrating them with databases like **MongoDB and MySQL** to ensure smooth data flow and scalability.  

Beyond coding, I am genuinely fascinated by **system design, API architecture, and DevOps practices**, and I constantly explore how emerging technologies — such as **cloud platforms, CI/CD pipelines, and containerization tools like Docker** — can improve project efficiency and reliability. I’m also an advocate for continuous learning and collaboration, regularly exploring open-source projects, developer communities, and online resources to stay current with industry trends.  

This repository is more than a simple profile — it’s a reflection of my journey as a developer: the technologies I work with, the projects I’ve built, and the passion that drives me to keep creating. My ultimate goal is to build software that not only functions flawlessly but also inspires creativity, innovation, and meaningful impact in the digital world.  

✨ *“Code is where creativity meets logic — and I strive to master both.”*
